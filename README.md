**AssistMindCubeXR**
AssistMindCubeXR es una aplicación de Realidad Extendida (XR) diseñada para la rehabilitación motora y la estimulación cognitiva de personas con diversidad funcional, especialmente aquellas afectadas por Daño Cerebral Adquirido (DCA). 

La plataforma ofrece una experiencia inmersiva donde los usuarios resuelven puzles tridimensionales, permitiendo adaptar la dificultad y registrar el progreso para apoyar el proceso de recuperación del paciente y el análisis del terapeuta.
